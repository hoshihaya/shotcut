# ShotCut

iPhone などで撮影した動画から、指定秒数のクリップを選び出すためのブラウザアプリ。  
選んだクリップを書き出す ffmpeg コマンドを生成する。連結は QuickTime Player などで行う。

## 起動

```sh
cd shotcut/
python3 -m http.server 8088
```

ブラウザで `http://localhost:8088` を開く。

> `BrokenPipeError` がターミナルに出ることがあるが、動作には影響なし（ブラウザが動画の読み込みを途中で切ったときに発生する無害なログ）。

## ディレクトリ構成

```
shotcut/
├── index.html        # アプリ本体（単一ファイル）
├── source/           # ソース動画を置く
│   ├── IMG_4962.MOV
│   └── ...
└── clipped/          # ffmpeg で切り出したクリップの出力先（自動生成）
```

## 使い方

### 1. 動画を読み込む

- **＋ 動画を追加** — 個別ファイルを選択
- **📁 フォルダを読み込む** — フォルダごと選択（ファイル名順で読み込まれる）
- 上記ボタンへのドラッグ＆ドロップも可（フォルダごと・複数ファイル可）

### 2. クリップ位置を決める

左ペインのリストでクリップを選び、上部のタイムライン（オレンジのウィンドウ）をドラッグして切り出し位置を調整する。

- **👁 N秒確認** — 選択位置から N 秒間プレビュー再生
- **▶ 最初から** / **▶ ここから** — 確定済みクリップを連続再生
- **✓ 確定** — 現在のクリップ位置を確定（もう一度押すと解除）
- **✓✓ 全確定** — 全クリップを一括確定

クリップ長は右上の **−／＋** で 1 秒単位で変更できる（デフォルト 2 秒）。

### 3. 順番を変える

- タイムライン上のセグメントをドラッグして並べ替え
- 左ペインのファイル名をドラッグして並べ替え
- **↕ 名前順に整列** でファイル名順にリセット

### 4. 保存・復元

- **💾 保存** — 作業状態を `shotcut-snapshot.json` としてダウンロード
- **↩ 復元** — JSON ファイルを選択して復元（JSON と同じディレクトリに動画ファイルがあれば自動で読み込む）
- JSON ファイルをアプリにドラッグ＆ドロップしても復元できる

### 5. 出力

1 つ以上のクリップを確定したら **📤 出力** ボタンが有効になる。  
クリップ作成用の ffmpeg コマンドが表示されるのでコピーしてターミナルで実行する。

```sh
# サーバ実行ディレクトリからの相対path
source_dir=source
mkdir -p clipped

ffmpeg -y -ss 12.34 -t 2 -i "$source_dir/IMG_4962.MOV" \
  -c:v libx264 -pix_fmt yuv420p -c:a aac -fps_mode cfr -ar 44100 \
  clipped/clip_001.mp4
...
```

- `source_dir` はフォルダ読み込み時は自動検出、個別ファイル読み込み時は `fixme` になるので手動で書き換える
- `clipped/` 以下にクリップが生成されるので、QuickTime Player などで連結して書き出す

## iPhone 動画について

- **VFR（可変フレームレート）対応**: `-fps_mode cfr -ar 44100` で固定フレームレートに変換
- **HDR（HLG）対応**: `-pix_fmt yuv420p` で 8bit に変換
- **Spatial Audio（apac）**: ffmpeg の警告が出ることがあるが動作に影響なし
